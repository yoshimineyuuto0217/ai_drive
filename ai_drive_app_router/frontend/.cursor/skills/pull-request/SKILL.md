# Pull Request

- 新しく作業するときは pull して最新の状態を持ってくる
- push するときは新しいブランチを切ってリモートに上げる
- ブランチ名は `feature/{機能名}`
- push したら PR を作成する
- PR 本文には対応内容を必ず記載する
  - 何を変更したか
  - なぜ変更したか
